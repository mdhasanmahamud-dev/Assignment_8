# Hero.IO

## Description
Hero.IO is a web application where users can explore information about various mobile and desktop apps. You can view app images, descriptions, ratings, reviews, and download counts. Users can easily search for apps, check ratings, and track the apps they have installed. The application is fully responsive and designed to provide a smooth and user-friendly experience.

## Features
- View detailed information about apps
- Analyze ratings and reviews using interactive charts
- Search and filter apps easily
- Track installed apps using LocalStorage
- Responsive navigation bar and footer
- Direct download links to Google Play and App Store

## Technologies Used
- **React.js** – For building the frontend
- **Tailwind CSS** – For responsive design and styling
- **React Icons** – For user interface icons
- **Recharts** – To display rating charts
- **LocalStorage** – To track installed apps
- **React Router** – For page navigation
